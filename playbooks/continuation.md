# Continuation

Use this when resuming work after interruption, transfer, or uncertainty about current state.

## Inputs

- The last durable result or decision trail.
- The current artifact state and authority boundary.
- The original objective and remaining constraints.

## Procedure

1. Reconstruct current state from durable artifacts, not memory alone.
2. Verify which claimed results still hold and which evidence has expired.
3. Restate the objective, completed units, open risks, and next smallest verifiable action.
4. Continue only after the new action has a clear owner, boundary, and proof.

## Result contract

Record: recovered state, stale or missing evidence, current decision, next action, and any authority needed before progress can continue.
